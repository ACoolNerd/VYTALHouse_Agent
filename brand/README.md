# VYTAL House Brand Integration — Agent

**Official brand version:** 1.0.0  
**Canonical source:** `ACoolNerd/VYTALHouse/brand-system`  
**Official positioning line:** **Renew • Restore • Recharge**

This repository governs the VYTAL House agent identity, system prompts, user-interface behavior, and brand-compliance checks.

## Required agent behavior
- Use only approved VYTAL House names, marks, colors, and positioning.
- Do not redraw or procedurally reinterpret the logo.
- Do not generate new taglines or use **Recovery • Contouring • Longevity** in new work.
- Use the official monogram for compact agent/avatar contexts and the full wordmark where space allows.
- Include accessible logo alternative text and use official theme tokens.
- Flag public medical, clinical, financial, legal, zoning, and investment claims for appropriate professional review.
- Apply **Rights • Disclosure • Proof** to partner and public-facing outputs.

The token files in this directory are synchronized from brand-system v1.0.0. Record future brand-version updates in release notes.
